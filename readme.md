# 📚 Repositorio de Aprendizaje

Bienvenido a mi repositorio de aprendizaje. Este espacio contiene documentación, laboratorios, ejercicios, notas técnicas y ejemplos prácticos relacionados con diversas tecnologías que estudio y utilizo en proyectos personales y profesionales.

## 🎯 Objetivo

Centralizar el conocimiento adquirido durante cursos, certificaciones, investigaciones y prácticas técnicas para facilitar:

- El aprendizaje continuo.
- La consulta rápida de información.
- La documentación de ejercicios y laboratorios.

## 📝 Convenciones

### Estructura de carpetas

```text
/
├── docs/
├── labs/
├── certifications/
├── scripts/
├── diagrams/
└── resources/
```

### Nomenclatura

- Archivos en minúsculas.
- Usar guiones (`-`) para separar palabras.
- Documentación en formato Markdown.

Ejemplo:

```text
azure-networking-fundamentals.md
power-bi-workspace-security.md
```
